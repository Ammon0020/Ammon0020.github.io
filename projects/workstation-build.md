Designed and built a high-performance workstation optimized for 3D rendering, photo editing, and multitasking in creative and IT workflows. Component selection was driven by benchmarks relevant to actual workloads, not spec sheets.

The build features a multi-core CPU optimized for Blender rendering, high-speed NVMe storage in a RAID configuration for project file access, and ECC memory for stability during long render jobs. Cooling is handled by a custom loop designed for near-silent operation under sustained load.

Cable management and airflow were planned from the start, with custom 3D-printed brackets for drive mounting and cable routing. The result is a machine that's as clean inside as it is powerful.
